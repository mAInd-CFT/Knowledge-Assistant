ПРОДУКТОВАЯ ЛИНЕЙКА

Решения для финансовой отрасли

Программные продукты и приложения для автоматизации банковской деятельности и финансовых процессов.

01ФЛАГМАНСКИЙ ПРОДУКТ

ЦФТ-Банк

Комплексная автоматизированная банковская система для управления основными направлениями деятельности банка.

  • Учёт банковской деятельности
  • Обслуживание физических и юридических лиц
  • Операции, платежи и банковские продукты
  • Интеграции и автоматизация бизнес-процессов
  • Поддержка высоких транзакционных нагрузок
Core banking systemВ Реестре российского ПО
02РОЗНИЧНЫЙ БАНКИНГ

ЦФТ-Ритейл банк

Комплекс приложений для организации обслуживания частных клиентов банка.

  • Розничные банковские продукты
  • Операции по счетам клиентов
  • Обслуживание банковских карт
  • Автоматизация розничных процессов
Retail banking
03ПЛАТЕЖИ И КАНАЛЫ

ЦФТ-Сервис Сьют

Решение для управления платежами, банковскими продуктами и денежной наличностью в каналах обслуживания.

  • Управление платежами
  • Работа с финансовыми продуктами
  • Организация денежных операций
  • Взаимодействие с платёжными сервисами
CFT-Service Suite
04КОРПОРАТИВНЫЕ ФИНАНСЫ

ЦФТ-Корпорация

Решение для управления и контроля корпоративных финансов организаций с распределённой структурой.

  • Управление корпоративными финансами
  • Контроль финансовых процессов
  • Автоматизация финансовых операций
  • Работа с распределённой структурой
Corporate finance
