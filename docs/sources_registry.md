# Реестр источников и индекс

## Область
Только АО «Центр Финансовых Технологий» (ЦФТ).

## Поля источника
- область индекса: `cft` (вне этой области источники не индексируются);
- canonical source URI / имя исходного файла;
- заголовок;
- SHA-256 `source_id`;
- SHA-256 версия очищенного содержимого;
- время получения/индексации (`retrieved_at`);
- дата публикации (`published_at`), если присутствует в источнике;
- раздел и страница, если извлечены;
- статус версии: staged / active / superseded;
- число индексированных фрагментов.

## Payload Qdrant
`source_id`, `version`, `chunk_index`, `chunk_text`, `source_uri`, `source_file`,
`title`, `section`, `page`, `retrieved_at`, `published_at`, `is_active`.

## Поддерживаемые форматы
PDF, DOCX, HTML/HTM, TXT, Markdown. Для обычного текстового PDF сначала используется
быстрый `pypdf`; для сканированных или смешанных PDF применяется Docling с OCR
(RapidOCR). DOCX обрабатывается `python-docx`, включая абзацы, заголовки и таблицы.
HTML очищается BeautifulSoup/lxml от навигации, скриптов и повторяющихся блоков.

Для OCR-профиля Docling-модели предварительно загружаются при сборке образа
`ingestion-ocr` в `/opt/docling/models`; путь задаётся через `DOCLING_ARTIFACTS_PATH`.
В образ включён RapidOCR checkpoint для кириллицы. Для сборки OCR-образа нужен доступ
к Hugging Face/сети; после сборки модели находятся внутри образа. Сканированные документы могут обрабатываться
значительно дольше обычных текстовых PDF.

Статистика и ошибки обработки сохраняются в `data/processed/ingestion_report.json`.


## Русский Snowball

Для лексического поиска используется FastEmbed `Qdrant/bm25` с `language="russian"`.
Это уже включает Snowball stemming и русские стоп-слова; отдельная библиотека в коде
не нужна. В 1.6.1 закреплён FastEmbed 0.9.1, а passage и query кодируются разными
методами (`embed` для документов, `query_embed` для запросов).
