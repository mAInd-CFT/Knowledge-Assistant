# CFT Knowledge Assistant — кратко для защиты

Агент отвечает исключительно по материалам АО «Центр Финансовых Технологий».

- Диалоговый веб-интерфейс, история и независимые сессии.
- RAG: локальный multilingual E5 (dense) + BM25 (sparse) + Qdrant RRF.
- Генерация ответов: DeepSeek API (`deepseek-flash`).
- Извлечение документов: Docling + RapidOCR; для простых текстовых PDF сохраняется быстрый pypdf-путь.
- Ответы содержат конкретные источники, разделы и страницы, если они доступны.
- Индексация версионируется; новая редакция активируется после загрузки.
- Prompt injection: источники и история считаются недоверенными данными; модель
  не имеет произвольных shell/SQL/HTTP-инструментов.
- Docker Compose запускает frontend, backend, PostgreSQL, Qdrant и ingestion.

OpenCode применяется только как вспомогательный инструмент разработки и не
запускается в Docker. Ollama не требуется: LLM предоставляется через DeepSeek API.
Dense-модель работает локально через FastEmbed/ONNX Runtime; PyTorch и CUDA не требуются. Docling + RapidOCR остаются в ingestion-образе для сложных PDF.


## Что улучшено в редакции 1.6

- Поиск учитывает контекст коротких продолжений разговора.
- В ответах используются нумерованные ссылки на найденные документы.
- Chunking сохраняет заголовки и страницы.
- Веб-сборщик ограничен allowlist и проверяет публичность DNS/IP и redirects.
- Сессии используют подписанный browser token, TTL и idempotency key.
- Добавлены backup/restore scripts и сценарии проверки prompt injection.

Известные границы: подписанный browser token не заменяет SSO; multi-replica Backend не включать без общего lock и проверенной балансировки; DeepSeek API остаётся внешней точкой зависимости; резервный LLM не настроен.


## Уточнение 1.6.1: BM25 / Snowball и OCR

- Snowball уже включён: `Qdrant/bm25` + `language="russian"` в FastEmbed
  автоматически выбирает русский Snowball stemmer и стоп-слова.
- Документные BM25-векторы строятся через `embed()`, запросы — через
  `query_embed()`. Это исправляет ранее неверное использование query encoding
  для обоих типов текста.
- Docling artifacts заранее загружаются в OCR-образ и путь задаётся явно.
- Для новой схемы sparse-векторов используется Qdrant collection v2; полная
  переиндексация обязательна.
